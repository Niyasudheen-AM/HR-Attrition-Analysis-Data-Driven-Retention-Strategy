# HR Attrition Analysis: Strategic Retention Mapping

##  Project Overview
This project provides a data driven solution to identify and mitigate employee turnover within a workforce of 1,473 individuals. By bridging the gap between raw data and business strategy, I developed a tool that transforms HR metrics into actionable retention roadmaps. The analysis focuses on identifying "Flight Zones" specific intersections of data where the probability of resignation is statistically highest.

##  Tech Stack
* **Data Engineering:** Python (Pandas) for cleaning, handling missing values, and feature engineering.
* **Visualization:** Power BI for interactive dashboarding and storytelling.
* **Modeling:** DAX (Data Analysis Expressions) for dynamic KPIs and custom measures.
* **Reporting:** Strategic PDF reporting for executive stakeholders.

##  Key Findings
* **The Gen Z Risk:** Attrition peaks at **35.8%** for the 18–25 age group.
* **The Burnout Factor:** Employees working overtime are **30.5%** more likely to exit.
* **First-Year Crisis:** Turnover is highest during the first year of tenure and during manager transitions.
* **Compensation Gap:** Significant attrition (22%) is concentrated in the "Upto 5k" salary slab.

##  Dashboard Preview
The interactive dashboard consists of two primary views:
1. **Workforce Demographics:** Analyzing age, gender, and salary distributions.
2. **Tenure & Growth Analysis:** Mapping the relationship between promotion, manager tenure, and exit rates.

##  Strategic Recommendations
The project concludes with a roadmap to reduce the current **16.09%** attrition rate through:
* Targeted salary market corrections for high-performing junior staff.
* Formalized mentorship programs for Gen Z integration.
* Burnout mitigation policies in high risk departments like Sales and Lab Tech.
