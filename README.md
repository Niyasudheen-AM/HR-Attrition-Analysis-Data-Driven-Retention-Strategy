# HR-Attrition-Analysis-Data-Driven-Retention-Strategy
In this project I used Python and Power BI to analyze a workforce of 1,473 employees. I built a cleaning pipeline and an interactive dashboard with DAX to map "Flight Zones" revealing high attrition among Gen Z (35.8%) and staff working overtime (30.5%). I provided strategic recommendations to reduce the 16.09% attrition rate.
